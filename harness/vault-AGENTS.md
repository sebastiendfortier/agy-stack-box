# Vault agent rules

This vault was bootstrapped from `agy-stack-box/harness/` so a fresh HPC clone
has a working CMC context without the workstation vault.

- Use the Obsidian MCP tools when connected; otherwise plain files are fine.
- `setup/` holds the harness plan, questionnaire (`status: partial`), and CMC profile.
- Keep lasting notes in `agent-sessions/`, `adrs/`, `lessons/`, `runbooks/`, and `glossary/`.
- Never write secrets, hostnames, queue names, or absolute HPC paths into notes that may be shared or committed.
